# Kobo Offline Translator

Experimental Kobo/KOReader build of the Firefox/Bergamot offline translation plugin, initially targeting the Kobo Clara BW.

The goal is to translate selected text locally on the Kobo, without Android, a phone, or an internet connection after language models have been downloaded.

This repository builds from the upstream project at https://github.com/anezih/offlinetranslator.koplugin.
